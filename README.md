# Quantum Computing Exploration

An independent, hands-on exploration of quantum computing fundamentals using Python and Qiskit.

This project is organised as a structured Jupyter Notebook, combining conceptual explanations, Python implementations, quantum circuit construction, simulation, and visualisation.

The notebook documents the progression from fundamental quantum computing concepts to building and executing quantum circuits.

## Project Overview

Quantum computing introduces a fundamentally different approach to information processing through quantum bits (qubits), superposition, entanglement, and quantum measurement.

This project explores these principles through practical implementations using Qiskit and local quantum circuit simulation.

## Notebook

**Quantum Computing Fundamentals.ipynb**

The primary project deliverable is a structured Jupyter Notebook containing:

- Conceptual explanations of quantum computing fundamentals
- Classical bits and quantum bits
- Quantum superposition
- Quantum gates and circuit operations
- Hadamard gate
- Controlled-NOT (CX/CNOT) gate
- Quantum entanglement
- Bell State circuit implementation
- Quantum measurement
- Local quantum circuit simulation
- Visualisation of measurement outcomes

Each section combines explanations with executable Python code to connect the underlying concepts with their practical implementation.

## Running the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/quantum-computing-exploration.git
cd quantum-computing-exploration
```

### 2. Activate the environment

```bash
conda activate quantum-exploration
```

### 3. Install dependencies

```bash
pip install qiskit qiskit-aer matplotlib
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Open `Quantum Computing Fundamentals.ipynb` and execute the notebook cells.
